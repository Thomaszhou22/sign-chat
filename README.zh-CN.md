# Sign Chat — 手语练习

帮听障人士的家人和朋友学手语。摄像头手势练习 + 实时反馈；你自愿上传的每个手势都会帮助重新训练识别模型——用的人越多，应用越好用。

**在线体验：** [sign-chat.vercel.app](https://sign-chat.vercel.app)

**[English](README.md)** | **中文**

## 功能

- 📷 **摄像头手势练习**——跟着做手势，实时获得反馈
- 🤝 **社区驱动模型**——经同意的手势上传用于重新训练识别模型
- 🎯 **面向听障者的亲友**——为听障人士身边的人设计，不只是手语学习者

## 技术栈

- React + TypeScript + Vite
- 浏览器摄像头 API + 手势识别模型

## 开发

```bash
npm install
npm run dev
npm run build
```
